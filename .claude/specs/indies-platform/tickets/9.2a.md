## What to build
1. **events fields (§7):** `at`, `site`, `name` (the §4 catalogue), `source` (`beacon` · `server`), `sessionId`,
   `path`, `locale`, `deviceClass`, `referrerHost`, `utm { source, medium, campaign }`, `props` (json, ≤ 2 KB
   validated), indexes `(site, name, at)` and `(sessionId)`. Keep 3.4's tests green or update them.
2. **Catalogue (§4):** `server/analytics/catalogue.ts` — every event name with a zod (or hand-written) schema of
   its props; `validateEvent(e)` drops unknown names and bad props, impossible values (negative counts, LCP > 60 s).
3. **Collect** `POST /api/x/collect`: order exactly as §6 — origin check (the two site hostnames from the
   allow-list, via `siteFromHost`; never trust `Host` for anything else), JSON body only, ≤ 20 events and ≤ 8 KB,
   empty or bot user agent dropped (a maintained list in `server/analytics/bots.ts` — crawlers, monitors,
   headless browsers, curl/wget/python-requests/axios/node-fetch/Go-http-client…), per-session rate (120/min) and a
   per-address burst limit (in-memory token bucket is fine; document it is per process), then stamp `site`,
   `sessionId` (cookieless per §2 — implement exactly what §2 specifies, e.g. a daily-salted hash; no cookie, no
   stored visitor id), `deviceClass`, normalised `path` (§3: drop the query except `utm_*` and a redacted search
   `q`; strip the tracking token from `/track/…` and `/id/lacak/…`), `referrerHost` (host only). Insert the batch
   with **one** statement through Payload's db adapter (drizzle) or the Local API in one transaction. Always answer
   `204` quickly; count dropped events per reason (a counter you export for the dashboard later).
4. **Beacon** `shared/beacon/beacon.ts` (client): `track(name, props)` queues, batches, sends with
   `navigator.sendBeacon` at most once per 5 s per tab, flushes on `visibilitychange`, never throws. No cookie,
   no localStorage id.
5. **9.2.c** `engine/tooling/no-trackers/cli.mjs` scans `engine/apps/web/.next/` output (HTML and JS) for Google
   Analytics/Tag Manager, Meta Pixel and other third-party tracker domains (googletagmanager.com,
   google-analytics.com, connect.facebook.net, facebook.com/tr, doubleclick.net, hotjar, segment…) and exits 1 listing
   hits; unit-test it on fixture strings.
