## What to build (pure library + tests; no network, no bucket calls in tests)
1. `derivatives/index.ts`: `export async function makeDerivatives(input: Buffer, opts?: { widths?: number[] }):
   Promise<Derivative[]>` where `Derivative = { width: number; height: number; format: 'avif' | 'webp'; bytes:
   Buffer; key: string }`. Default widths `[320, 640, 960, 1280, 1600, 2400]`, never upscaled (skip widths above
   the source width, but always emit at least the source width once). Strip all metadata (EXIF location included)
   — `sharp().rotate()` to bake orientation, then no `withMetadata`. Keys follow the media contract's naming for
   derivatives (read `contract.ts`; do not invent a new scheme).
2. `tiles/index.ts`: `export async function makeTiles(input: Buffer, opts?: { tileSize?: number }): Promise<{
   files: { key: string; bytes: Buffer }[]; info: object }>` producing a static IIIF Image API level-0 tile
   pyramid with sharp's `.tile({ layout: 'iiif3', size: 512 })` (or 'iiif' if the contract says v2) into a temp
   directory, then read back into memory and delete the temp dir. Keys under the contract's `iiif/` prefix.
   `info` is the parsed `info.json`.
3. A helper `isLowResolution(width: number, height: number): boolean` (long edge < 1600 px) the viewer uses to be
   honest about legacy photos.

## Tests (by name, in `*.test.ts` beside each)
"never upscales a small image"; "emits AVIF and WebP for each width"; "strips EXIF GPS data" (build a JPEG with
sharp `withMetadata({ exif: { IFD3: { GPSLatitude: … } } })` or similar, assert the output has no `exif`);
"tiles produce an info.json and level-0 tiles under iiif/"; `isLowResolution` edges.
