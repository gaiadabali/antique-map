## What to build — pure functions with explicit inputs, no Payload calls
1. `metadata.ts` — `pageMetadata(input: { site: SiteKey; locale: 'en' | 'id'; path: string; title: string;
   description: string; image?: { url: string; alt: string; width?: number; height?: number }; noindex?: boolean;
   origin: string }): Metadata` → title, description, `alternates.canonical` (absolute, `origin + /{locale}{path}`),
   `alternates.languages` for `en`, `id` and `x-default` (→ `en`), Open Graph (type website, locale `en_GB` /
   `id_ID`, siteName from a constant per site: "Indies Gallery" / "Old East Indies") and Twitter card. The origin
   is a parameter — never read from a request. `workTitle(title, maker?, year?)` →
   `"{title} – {maker}, {year} | Indies Gallery"` with graceful omission.
2. `json-ld.ts` — `workJsonLd(work)` → `VisualArtwork` with `name`, `creator` (Person/Organization by name),
   `dateCreated`, `width`/`height` (`QuantitativeValue`, cm), `artMedium`, `spatialCoverage` (Place names),
   `identifier` (stock number), `image`, `url`. It must NEVER include `offers`, `price`, `priceCurrency` or
   `Product` — enforce with a final guard that throws if any of those keys appear anywhere in the object.
   `productJsonLd(product)` → `Product` with `sku`, `name`, `image`, `brand` (Old East Indies), `offers` (`Offer`,
   `priceCurrency: 'IDR'`, `price` as the integer rupiah string, `availability` InStock/OutOfStock, `url`).
   `breadcrumbJsonLd(items: { name: string; url: string }[])`, `organizationJsonLd(site, origin)`.
   `jsonLdScript(obj)` → the safe string for a `<script type="application/ld+json">` (escape `<` as `<`).
3. `sitemap.ts` — `buildSitemap(entries: { path: string; lastModified?: Date }[], origin: string): string`
   producing sitemap XML with an `xhtml:link` alternate for `en` and `id` per entry (each entry is a path without
   the locale; both locales are emitted), XML-escaped; and `excludedPrefixes = ['/admin', '/api', '/track',
   '/checkout', '/bag', '/order']` with `isIndexable(path)`. Sold antiques stay listed (no filtering by status here).
4. `robots.ts` — `buildRobots(origin: string, { allowIndexing: boolean }): string` — `Disallow` for the excluded
   prefixes, `Sitemap: {origin}/sitemap.xml`; when `allowIndexing` is false (staging) `Disallow: /` for all.
5. Wire the two `/api/x/{sitemap,robots}` routes to these builders with the path list left as a clearly named
   stub `loadSitemapPaths(site)` returning the static pages (home, about, browse/shop, contact) — the loaders of
   phases 5/6 replace the stub. Staging is never indexable: `allowIndexing` is true only when an env flag
   `SEO_ALLOW_INDEXING=1` is set.

## Tests (by name)
"canonical and alternates are absolute and use the given origin"; "x-default points at en"; "a gallery work's
JSON-LD never contains offers or price" (and the guard throws when fed one); "a product's JSON-LD has an IDR offer
with an integer price"; "jsonLdScript escapes </script>"; "the sitemap lists both locales per path and escapes &";
"excluded paths are not indexable"; "robots disallows everything unless indexing is allowed".
