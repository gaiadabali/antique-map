## What to build
1. **Chrome (4.3.a)** — each site's header (logo, primary nav per the drawing, language switch EN/ID keeping the
   current path, the chat entry button rendered **inert** with `aria-disabled` until phase 8, a contact link from
   `site-settings`), footer (contact, hours, the two-way bridge link to the sister site with the brief's wording,
   legal links as placeholders), all built from `shared/ui` components and tokens, copy from the lexicon. Contact
   values come from a server loader reading `site-settings` (owner-only collection — read it in the server loader
   with `overrideAccess: true` **and an explicit `select` of only the public contact fields**; document why in the
   loader header). If `site-settings` is empty, render the lexicon's placeholder text marked as such.
2. **Homes (4.3.b)** — the gallery home (hero with the drawing's film slot as a poster image placeholder, featured
   items, makers and places entry points) and the shop home (per its drawing), composed only of `shared/ui`
   components and small section components in `sites/*/home/`. Featured items come from loaders in
   `server/{gallery,shop}/home/` that call Payload with **`overrideAccess: false`, `_status: 'published'`, and a
   `select` of only the shown fields** (never `askingPrice` or any price on the gallery; shop prices via
   `formatRupiah`), wrapped in `'use cache'` with `cacheTag('works')`/`cacheTag('products')`, rendered inside
   `<Suspense>` with a skeleton, and resilient to an empty database (an empty state, never a crash). The build must
   stay green with no `DATABASE_URL`.
3. **Partnership page (4.3.c)** — the shop's partnership page from the drawing; its last section is an enquiry call
   to action (WhatsApp and email buttons with a prepared message, and a short form whose submit is a placeholder
   that 9.1 wires to a `partnership` lead) — no sign-up or sign-in.
4. **Lexicon (4.3.d)** — delete dead keys (account, bag-as-account, payment, order, offers — keep anything the shop
   still uses: check usages), add every new key in `en` **and** `id` (*Anda* voice, British spelling), and a unit
   test `sites/lexicon.test.ts` that every key has both values and none is unused (scan the source for key usage).
5. Both hosts at 390 px and 1280 px, axe-clean, no raw colour (`pnpm check:tokens`), no hard-coded copy.
