## What to build (exact)
1. `shared/styles/tokens/` three tiers as CSS custom properties: `primitives.css` (raw scales: colour ramps, space
   4-px scale, radii, shadows, durations, easings, type sizes), `semantic.css` (aliases components use:
   `--color-surface`, `--color-surface-raised`, `--color-text`, `--color-text-muted`, `--color-accent`,
   `--color-accent-contrast`, `--color-border`, `--color-focus`, `--color-danger`, `--color-success`,
   `--font-display`, `--font-body`, `--text-h1` … `--text-small`, `--space-*`, `--radius-*`, `--shadow-*`,
   `--motion-*`), each pointing at tier-2 brand variables.
2. Tier 2 per site: `sites/gallery/tokens/brand.css` (quiet luxury: the design team's linen, off-black, bronze,
   champagne) and `sites/shop/tokens/brand.css` (warmer, friendlier, same variable names, visibly a sibling),
   each scoped to `[data-site="gallery"]` / `[data-site="shop"]` on `<html>` (the layout sets that attribute in
   4.3; also set the gallery values on `:root` as the default). No dark mode.
3. Fonts per the owner's decision (TASKS.md Decisions → **Fonts**): `shared/styles/fonts.ts` exporting
   `display` = Cormorant Garamond (400, 500, 600) and `body` = Karla (400, 500, 700) via `next/font/google` with
   `variable: '--font-display-face'` / `'--font-body-face'`, `display: 'swap'`, subsets latin. Export
   `fontVariables = \`${display.variable} ${body.variable}\``. The semantic tokens use those faces with a system
   fallback stack. Sizes and weights of DESIGN-SYSTEM §2 each become a token (H1 40–80 px fluid with `clamp()`,
   −0.015em; H2 38 px; card title 25 px/500; numerals 40 px; body 14–15 px; price 15 px/700; tagline capitals
   0.14em; announcement 13 px). Applying `fontVariables` to `<html>` is a layout edit you must NOT make — list it
   under Follow-ups.
4. Move every raw colour and `font-family` now in `src/styles/*.css` into tokens; `site.css` uses only `var(--…)`.
5. The lint (4.1.d): a script `engine/tooling/token-lint/cli.mjs` that scans `engine/apps/web/src/**/*.{css,tsx,ts}`
   **outside** `shared/styles/tokens/**` and `sites/*/tokens/**` and fails (exit 1, listing file:line) on a hex
   colour (`#abc`, `#aabbcc`, `#aabbccdd`), `rgb(`/`rgba(`/`hsl(`/`hsla(`, or a `font-family:` declaration.
   Add `"check:tokens": "node engine/tooling/token-lint/cli.mjs"` and append `pnpm run check:tokens` to the
   `verify` chain. Unit-test it (`cli.test.mjs` or `.ts` beside it, run by the repo's vitest): a planted `#ff0000`
   in a fixture component fails; the same value in a token file passes; `font-family: Arial` fails.
6. `DESIGN.md` (repo root, under 150 lines): what was adopted from the design team, what we added, and the swap
   points (the two `brand.css` files for palettes — the client's final colours Q16 are an edit there; `fonts.ts`
   for the family; hero media).
