## Build, in this order (commit after each)
1. **Loader** `server/gallery/item/load-item.ts`: `loadItem(publicId: string, locale: Locale): Promise<ItemView | null>` — Payload Local API with `overrideAccess: false`, `where: { publicId: { equals }, _status: { equals: 'published' } }`, an explicit `select` that **never** includes `askingPrice`, internal notes or anything staff-only (start from `WORK_CARD_SELECT` and add only: description, provenance/references text, condition grade + notes, dimensions, technique/subject terms, maker, place, date reading, all images with alt text and roles, status, stockNumber). Returns `null` for unknown, draft or malformed ids. `ItemView` is a plain, serialisable view model in `server/gallery/item/view-model.ts`. Db test `load-item.db.test.ts`: "a draft is null"; "the projection carries no askingPrice" (assert on `JSON.stringify` of the result); "an unknown id is null".
2. **The page** `app/(gallery)/gallery/[locale]/product/[id]/page.tsx` (plus a slug segment only if EXPERIENCE-GALLERY's one-address rule names one — follow the doc): images, title, maker, place, date, dimensions, technique, condition grade, provenance text, the words "Price on request" (lexicon) and **no number that looks like a price anywhere**; breadcrumbs back to browse; an "Ask about this" button that links to `/contact` for now (5.3 replaces it with the WhatsApp builder — take the href as a prop and leave a `TODO(5.3)` comment). One address: a non-canonical address answers **308** to the canonical one (`permanentRedirect`), unknown → `notFound()`. `generateMetadata` calls the 9.3 library only. The page is a thin composition: sections live in `sites/gallery/item/*.tsx`, each under 300 lines, tokens and shared components only, copy from the lexicon.
3. **Zoom viewer** `sites/gallery/item/zoom-viewer.tsx` (`'use client'`, loaded with `next/dynamic` and `ssr: false`): OpenSeadragon inside `ZoomShell`; pinch, wheel, keyboard (+ / − / 0, arrows), full screen; tile source = the image's IIIF `info.json` under `iiif/` (key builder from `packages/media/src/tiles`); when there are no tiles, fall back to the largest derivative as a simple image source (and to the media's own URL if no derivative exists); when the image is a low-resolution legacy photo (longest side < 1600 px), show the shell's `lowResolutionNotice` from the lexicon. Thumbnails switch the image. No zoom JS loads until the visitor opens the viewer (a "Zoom" button), so the page stays fast.
4. **Sold and on hold (5.2.d)**: `status: 'sold'` → a "Sold" badge, the item stays at its address, **no** Ask button and no "available" wording; `on-hold` → "On hold" badge, Ask still shown. Test `item-status.test.tsx` covers the three states.
5. Board: `pnpm tasks:report 5.2.b` once step 2 renders, `5.2.c` after step 3, `5.2.d` after step 4. Never tick 5.2.e.
