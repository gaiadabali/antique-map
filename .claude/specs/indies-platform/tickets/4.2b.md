## What to build
- **StatusTimeline**: ordered steps `{ key, label, at?: string }[]` and `current`; done/current/upcoming states,
  `aria-current="step"`, times in a `<time dateTime>`.
- **MapPinShell**: the frame of the pin picker — a slot for the map, an address line, a "use my location" button
  and a fallback "paste a Google Maps link" input; no Maps code (6.3 adds it).
- **ZoomShell**: the frame of the deep-zoom viewer — a slot, full-screen toggle (`requestFullscreen` guarded),
  zoom in/out/reset buttons with labels from props, and a `lowResolution` notice slot.
- **ChatShell**: panel frame — header with title and close, a scrollable log (`role="log"`, `aria-live="polite"`),
  a composer slot, a disclosure line slot.
- **FacetChip** (toggle button with `aria-pressed`, a count), **Pagination** (`<nav aria-label>`, prev/next and
  numbered links via `next/link` with `prefetch={false}`, current `aria-current="page"`), **Breadcrumbs**
  (`<nav aria-label>` + `<ol>`, last item `aria-current="page"`).
- **Price**: `formatRupiah(amount: number): string` — integer rupiah in, `Rp 1.250.000` out (id-ID grouping, no
  decimals); throws on a non-integer; the component renders it in `--text-price`. Unit-test the formatter.
- **ResponsiveImage**: `next/image` wrapper requiring `alt` and `sizes`, with a `fill` variant and an aspect-ratio
  box.
