## What to build
1. **Collection:** add `'410'` to `REDIRECT_CODE_LABELS` (`{ en: 'Gone (410)', id: 'Hilang (410)' }`); when
   `code` is `410`, `to` is not required (make `to` optional at the field level and validate: required unless
   code is 410; empty when 410). The builder in `migrate` already emits `code: 410, to: ''`. Regenerate types.
2. **The map loader** (`legacy/payload-redirects.ts`, loaded by `import()` like `payload-queue.ts`): reads all
   `redirects` rows for one site with the Local API, `select: { from, to, code }`, paging through every row
   (≈7,000 gallery rows — use `pagination: false` or pages of 1,000), returns a `RedirectMap` keyed by
   `redirectKey(site, from, '')` exactly as 9.4a's builder keyed them (rows' `from` already carries its kept
   query). This is a server-only read of non-public config, never rendered: use `overrideAccess: true` and say
   why in a comment (the collection's read access is staff-only by design). Codes arrive as strings from the
   select — convert to numbers.
3. **The cache:** one in-process map per site with a TTL (5 minutes) and single-flight loading (two requests at
   once trigger one load). A failed load is not cached: log once with `describeError`, answer 404 for that
   request. No `'use cache'` (the route is per-request) and nothing at import time.
4. **The route** (`legacy/route.ts`): a factory `legacyRoute(load = defaultLoader, now = Date.now)` and
   `export const GET = legacyRoute()`. The site comes from the proxy's request header
   (`PROXY_REQUEST_HEADERS.site` in `@engine/http/manifest`); the public path and query from
   `PROXY_REQUEST_HEADERS.publicPath` and the request URL's search (the proxy rewrite carries the query — check
   which header or URL holds it and test it). No site header → plain 404. Then `resolveRedirect(site, map, path,
   search)` → **301/302** with `Location` (an absolute URL on the site's canonical origin when `to` is a path —
   `siteOrigin(site)` from `@engine/config/sites`; an absolute `to` stays as is), **410** plain text, or **404**
   plain text. Every answer `Cache-Control: no-store`? — no: 301 and 410 may be cached by browsers; use
   `Cache-Control: public, max-age=3600` on 301/410 and keep `no-store` on 404. HEAD answers like GET without a
   body (export `HEAD`). One hop only: the resolver never follows `to`.
5. Update the stub's doc comment (it says "until 36.4") to describe the real behaviour.
