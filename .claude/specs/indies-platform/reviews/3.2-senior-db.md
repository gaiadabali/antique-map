## Findings

- **B1 blocker** — `collections/users/guards.ts:162-187`: the last-admin count runs unlocked and bulk operations run per document in parallel. Two concurrent demotions, one bulk `update where roles in [admin]`, or one bulk delete → 0 admins. Fix: `pg_advisory_xact_lock` before counting in both hooks; a `beforeOperation` guard resolving a bulk `where` to ids; a hand-written `CONSTRAINT TRIGGER … DEFERRABLE INITIALLY DEFERRED` on `users_roles` raising when users exist and no admin remains. Real-DB tests for concurrent and bulk.
- **S1** — `db/tables/idempotency-keys.ts:43`: the composite primary key, not the stack, breaks dev push (drizzle-kit 0.31.7 drops params on the composite-PK introspection query, `api.js:166295`, `:44743`). Fix: `unique(...).on(operation, key)` with NOT NULL columns; `declareEngineTables` refuses composite primary keys; fix comments `db/adapter.ts:10-12`, `db/schema-diff.ts:8-12`; the storage contract says "unique", not "primary key" (ARC).
- **S2** — `guards.ts:147-160`: `registerFirstUserOperation` checks for users before the hook, unlocked, and creates with `overrideAccess: true`, so a losing racer keeps the roles it sent (three racers → two admins). Fix: under the lock, `totalDocs > 0 && req.payloadAPI !== 'local' && !hasRole(req.user,'admin')` → Forbidden; fix `users.test.ts:89`. Consider a CLI/seed first admin before a deployed database is reachable.
- **S3** — `idempotency-keys.ts:37`: `response` NOT NULL contradicts `LOCK_ORDER` (the dedupe insert comes first); make it nullable (confirm with DOM).
- **S4** — `access/published.ts:20`: unset `readVersions` / `readDrafts` falls back to `Boolean(req.user)` — a signed-in buyer could read every draft through `/versions`. Fix: `DRAFTED_ACCESS = { read: publishedOrStaff, readVersions: isStaff }`; `registeredCollections()` throws for a drafts collection lacking both; globals too.
- **N1** — `db/adapter.ts:72-89`: `migrate:down/fresh/refresh/reset` run unlocked; wrap them.
- **N2** — `db/advisory-lock.ts:51`: add `client.on('error')` that logs and exits; document `DATABASE_URL` must be direct/session-mode (no transaction pooler); `idle_session_timeout` risk.
- **N3** — later migrations: `generate-migration` adds `SET LOCAL lock_timeout = '5s'` to `up()`.
- **N4** — `migrations/…initial.ts:9-10`: `CREATE EXTENSION IF NOT EXISTS … WITH SCHEMA public`.
- **N5** — `idempotency_keys`: `COLLATE "C"` on `operation`, `key`, `caller_ref`; bound the key length; partial `caller_ref` index; `operation` not blank.
- **N6** — `db/schema-diff.ts:59` compares snapshot versions as strings.
- **N7** — `db/engine-tables.ts:42` uses bare `pgTable`; use the adapter's schema.
- **N8** — a lone admin can be locked out repeatedly; rate-limit `/api/users/login` at the edge (ARCHITECTURE §13, 41.1).
