## Findings

1. **should-fix (ARC)** — `i18n/src/locales.ts:8`, `src/money.ts:13` import `LOCALE_CODES` / `CURRENCY_EXPONENT` from `@engine/config/schema`, which builds the zod schema at import. Measured `import { formatMoney } from '@engine/i18n'`: 107.8 KB min / 31.9 KB gzip, vs 0.7 KB with a zod-free stub — ~21% of the 150 KB first-party initial-JS budget (DESIGN-SYSTEM §7). Fix: a zod-free `@engine/config/constants` leaf that `schema/*` re-export; i18n imports it; `client-safe.test.ts:28` asserts no `zod` is reached. Before 4.1 ships a client formatter.
2. **should-fix** — `http/src/proxy/decide.ts:117` strips only `content-security-policy`; Next reads the nonce from `content-security-policy-report-only` too (`app-render.js:167`). A client-sent report-only header sets the page's nonce while no builder is passed or it returns null. Fix: always delete both; test it.
3. **should-fix** — `decide.ts:11` promises a module-off surface is not-found, but only a segment omitted from the config achieves it (C1 allows keeping it; `checkSegments` doesn't reject it). OEI with `purchase.invoices` off and `quote` kept serves `/quote/abc`; likewise gated form kinds and account sections. Fix: `modules` in `ProxyConfig`, `hasModule()` after parsing, a test with one module off.
4. **should-fix** — `decide.ts:54` rewrites to `/_not-found`; with two root layouts (`(site)`, `(payload)`) that renders Next's default unbranded 404, not `(site)/[locale]/not-found.tsx`. Fix: target `/${locale}/not-found`, backed by `(site)/[locale]/not-found/page.tsx` calling `notFound()` (4.1); the spike asserts 404 status, masthead, `x-public-path`, JS off. The 3.1.e "404 for internal paths" clause is proven as a proxy decision; the status part closes at 4.1.e.
5. **should-fix** — `copy.ts:87-102`, `messages.ts:56` require every plural category for every locale; Indonesian has only `other`, so `id.json` is reported missing `cart.items.one` (tests bake it in, `locales-messages.test.ts:85, :141`). Fix: require only `Intl.PluralRules(locale).resolvedOptions().pluralCategories`; a non-`other` form may carry a subset of placeholders.
6. **nit** — `messages.ts:55` `??` renders `""` blank and doesn't count it missing; treat `''` as absent in the loader and `checkCopy`.
7. **nit** — pinned fraction digits don't make server and browser text identical (symbol, spaces); soften the hydration claim; convention: Client Components receive preformatted strings.
8. **nit** — `locales.ts:76` `suggestLocale` ignores legacy `in-ID`; map `in` → `id`.
9. **nit** — `dates.ts:100-107` `formatCalendarDate` rolls `2026-02-30` into March; validate by UTC round-trip and throw.
10. **nit** — `respond.test.ts` ~93 no-DB regex misses `process.env.DATABASE_URL`; drop the trailing quote class.
11. **nit** — `decide.ts:58` hard-codes `payload-lng`; Payload's cookie is `${cookiePrefix}-lng` — derive it or note for 3.2.
12. **nit (ARC)** — `/apple-touch-icon(-precomposed).png`, `/site.webmanifest` hit the designed 404 and its loader; consider C13 `ROOT_REWRITES`.
13. **nit (ARC)** — C10 `parse.ts:97` `decodeAll` serves `/pr%6Fduct/1706` at a second address with 200; reject segments that don't survive decode-then-encode.
