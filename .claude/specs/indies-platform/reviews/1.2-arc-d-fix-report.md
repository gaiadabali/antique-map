## Decisions taken (where the reviewers offered options)

- **Lock order:** dedupe → request → **orders → payment_attempts** → reservations (`target_key` COLLATE "C") → stock_levels (variant, location) → counters, with the document sequence last. This deviates from db#1, which put attempts first; **senior-db asked to confirm.** Sweeps start with `FOR UPDATE SKIP LOCKED`.
- **Multi-target writes:** `reserveAll()`, all-or-nothing under a savepoint. extend, release, convert and reverse take ids in bulk.
- **Isolation and timeouts:** `DOMAIN_TX_ISOLATION = 'read committed'`. `DOMAIN_TX_TIMEOUTS`: lock 5 s, statement 15 s, port 10 s — ARC-D's own values, awaiting confirmation.
- **Duplicate payments:** a new order row, `duplicate-payment-refused`, with a refund keyed `dup:{attemptId}`.
- **Unmatched events:** go to `payment_events_unmatched` and don't consume the dedupe key.
- **Early events:** `retrieve()` and catch-up, outcome `caught-up`.
- **Refunds:** applied once, when `(attempt, refundRef)` is new and the running total rises. Refund keys: `late:`, `dup:`, `staff:`. A refund is recorded as owed before the provider is called, and the reconciler retries it.
- **Counted returns:** stock adjustments. `reverse` handles exclusive targets only.
- **A refund made at the provider:** alerts staff only (`order.refundedAtProvider`). `ReverseReason` no longer includes `'refunded'`.
- **A late payment from `pending_payment`:** a new row, `--late-payment-refused--> abandoned`.
- **Offers:** `submitted|countered --item-unavailable--> declined`, emitting `offer.closedUnavailable`.
- **payment.status:** POST only, scoped to a checkout, a pay link, or an order via `OrderAccess`.
- **Webhooks:** per seller, `/api/x/webhooks/payments/[provider]/[seller]`. The dedupe key is `(provider, seller_id, provider_event_id)`.
- **FX buffer:** C5 keeps `bufferPct` as a percent decimal string. C1 must match.
- **Shipping ETA:** the domain adjusts it, so `RateRequest.deliverBefore` is removed.
- **Pricing tokens:** any change to the bag mints a new token. There is no `checkout.applyCode`.
- **SCH DDL notes** are in `engine/packages/domain/src/contracts/storage.ts` (`@engine/domain/storage`), along with `RESERVATION_ARBITER`, the partial-index predicate shared by SCH's index and DOM's `ON CONFLICT`.
