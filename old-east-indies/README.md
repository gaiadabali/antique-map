# Old East Indies — brand folder

Merchandise made from the Indies Gallery archive — giclée prints, posters,
postcards, notebooks, homeware and gifts — sold online and from the showroom at
Jl. Gambuh 17, Denpasar. Runs on the **`emporium`** storefront app
(`engine/apps/emporium`).

**This folder holds configuration, data and assets — never application code**
(docs/BRANDS.md §2).

| Path | Holds |
| ---- | ----- |
| `site/brand.config.json` | the brand's configuration (created in task 0.6.d) |
| `site/assets/` | logo, marks, favicons, OG base, licensed fonts |
| `site/copy/` | per-locale copy overrides |
| `content/seed/` | starter content |
| `content/legacy/` | old `oldeastindies.com` Squarespace URLs and the product list import (docs/MIGRATION.md §10) |
| `db/` | dumps (gitignored) |

Product brief: `engine/apps/emporium/PRODUCT.md`. Visual world:
`engine/apps/emporium/DESIGN.md` (written in Phase 1). Experience:
`docs/EXPERIENCE-SHOP.md`.
