# Daftar foto (*shot list*) — peta

> **Draf — menunggu tinjauan penutur asli (D20).**
> English: [map.md](map.md)

Untuk peta, peta laut, dan denah kota. Siapkan seperti di [panduan galeri](../gallery-guide.id.md)
§4–§6: latar gelap, cahaya rata, kartu warna dan penggaris di samping lembar, kamera tepat
di atas. **Tanpa tangan di foto mana pun.** Beri nama file `<stock>_<role>_<nn>` (lihat
[serah terima](../handover.id.md) §2).

"Cahaya rata" (*copy light*) berarti dua lampu dari kedua sisi, atau jendela dengan
reflektor, seperti di panduan galeri.

| # | Foto | Peran | Cahaya | Perlu | Agar tepat |
| - | ---- | ----- | ------ | ----- | ---------- |

| 3 | seluruh bagian belakang | `verso` | cahaya rata | **selalu** | juga jika kosong — "Bagian belakang: kosong" adalah bagian dari catatan; teks atlas di bagian belakang menunjukkan edisinya |

## Jika peta lebih besar daripada yang dapat diambil kamera Anda pada 240 ppi

Tetap foto seluruhnya — itulah foto bagian depannya, dan itu sudah cukup untuk situs
(panduan, §3). Jika peta itu penting untuk cetakan Old East Indies, tuliskan di catatan;
pemotretan per bagian dapat menyusul.

## Sebelum mengirim

- [ ] Bagian depan, bagian belakang, dan setidaknya satu detail — set untuk peluncuran.
- [ ] Satu detail untuk setiap cacat yang disebut dalam catatan kondisi.
- [ ] Kartu dan penggaris terlihat di setiap foto kecuali foto cahaya tembus.
- [ ] Setiap foto sudah diperiksa dalam ukuran penuh: tajam di sudut-sudut, tidak ada tepi
  yang terpotong.
- [ ] Catatan karya: ukuran, cacat, passe-partout atau bingkai, kamera dan cahaya.
