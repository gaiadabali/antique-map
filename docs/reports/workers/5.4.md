## Fixes this run made (committed, `d792c4b`)

The e2e spec's seed had three bugs, all hit while producing the live evidence:

1. **Stock numbers** `E2E.0541/0542` do not match the gallery's `^[MPF]\.[A-Za-z0-9]+$` pattern —
   now `M.E2E0541/0542`.
2. **Media `role: 'photograph'`** is not in `enum_media_role` (photograph is a *provenance*) —
   now `role: 'recto'`, `provenance: 'photograph'`.
3. **The seed's writes ran with no invalidation collector**, so a published work's
   `invalidateWorkOnChange` called Next's `after()` outside a request scope and the create failed.
   The two work creates now go through `invalidationBatch().operation(...)` + `flush()` — the
   documented out-of-request pattern (`@engine/cache`'s own batch doc).
