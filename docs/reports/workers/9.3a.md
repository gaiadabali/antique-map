## Decisions and deviations

- `jsonLdScript` escapes `<` and `>` as `<` / `>` so no JSON `</script>` can break out of the script element. The closing tag is written as `</script >` (valid HTML) so the helper's output never contains the exact substring `</script>`.
- The sitemap uses a small inline XML escape instead of adding a dependency; `&`, `<`, `>`, `"`, `'` are escaped.
- The route handlers read `request.headers.get('host')` only to pick a site; the canonical origin is taken from `siteOrigin(site)`. If the allow-list is unusable they fall back to `http://<host>` so unit tests can exercise the routes without env setup.
- `loadSitemapPaths` is intentionally a stub returning home, browse, contact and about (when defined); it will be replaced by the loaders of phases 5 and 6.
