## Seed a local preview

From the repo root of a checkout with `.env.local` (`pnpm worktree:env …` done). `db:fresh` creates the
database **if missing** and migrates — it does not empty one, so start from `db:drop` for a truly fresh
database (it drops only the checkout's own suffix). Times measured on this machine (2026-10-05):

| # | command | time | result |
| - | --- | --- | --- |
| 1 | `pnpm db:drop` | seconds (not timed) | `[db] dropped indies_<suffix>` |
| 2 | `pnpm db:fresh` | 17 s | migrated, `ready` |
| 3 | `pnpm data:seed --layer vocabulary` | 26 s | places 66, terms 110, makers 127, site-settings seeded |
| 4 | `pnpm data:seed --layer gallery-sample` | 21 s | 50 works created (drafts) with their 65 committed images; review marks carried on 50 |
| 5 | `pnpm data:seed --layer shop` | 2 m 40 s | 80 products (+64 variant rows), 120 stores, 7,227 stock rows, 1 discount |

Step 3 is optional (every other layer seeds the vocabulary first) but makes it visible on its own.
Checked on the result: `works 50 | works with images 50 | images 65 | products 80 | stores 120 |
stock_levels 7227`. **Every seeded work is a draft** — the seed never publishes; a public page shows them
only once published (the CLI has `--publish`, which saves through the publish checks — **not run in
this ticket**), or in the admin's draft preview. Media lands in `engine/packages/cms/media/` (git-ignored).
