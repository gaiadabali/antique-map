### Found

- `@engine/cache` expires a work's tag at `'max'` (stale-while-revalidate): the **first visit after a work is marked
  sold still renders it as available** ("Price on request", "Ask about this"); the next visit is correct. By design
  in `invalidate.ts`, but it contradicts EXPERIENCE-GALLERY §9 "Sold" for that one render.
- `engine/packages/cms/package.json` on main lists `"./admin/views"` twice in `exports` (from main; harmless to
  Node, but a lint target).
- `whatsapp.viewing` in the lexicon has no `{city}` although §8's row is "a viewing in {city} of …"; the builder
  now passes `city`, so only the lexicon value needs it (not changed: the ticket allows adding keys only).
- TASKS.md 5.3.b/5.3.c still describe photos, type-sniffing and re-encoding; the owner's 2026-10-06 decision is
  no photos.
- The shared dev Postgres dropped connections during the run (`cannot begin transaction: Connection terminated
  due to connection timeout`), which took the local server down once; no code involved.

### Follow-ups

  available), or read status live.

  `Host`.
- SECURITY.md §2.10 says lead forms are "5 per hour"; the service is 10 per minute (owner decision 2026-10-06) —
  update the doc.
