## What I found from the stopped GLM run (job step 1)

The uncommitted work was read in full before anything changed. Kept: the lexicon approach (`copy.ts`, the
same pattern as `home-messages.ts`), the beacon wiring through `shared/beacon`, and the general split. Rewritten,
because it could not work or broke a rule:

- **The browse page parsed public paths and ad-hoc params the page never receives.** The proxy rewrites every
  browse URL to `/gallery/<locale>/browse?<canonical listing query>` (`parsePublicPath()`), and drops any
  parameter outside `FACET_KEYS`/`sort`/`page`/`q`. So the run's `sold=1`, `yearFrom`/`yearTo` and its
  `[[...facets]]` path parsing never reached the page. The page now reads `parseListingQuery()`, and a new pure
  module `server/gallery/catalogue/url-state.ts` maps the listing query to and from `FacetState`. The vocabulary
  is the contract's: `availability=sold` for "Include sold", `place=java/batavia` (the gazetteer path) for place,
  `date=18` for a century chip, and `date=1700-1800` for the year pair. Every link is `href()` of a state, so the
  route map decides path segments (`/antique-maps/java`, `/id/peta-antik`).
- **A syntax error** in `search-view.test.tsx` (an apostrophe inside a single-quoted test name). The suite never
  ran.
- **Components imported values through the `server-only` barrel**, so the component tests could not load. They
  now import from the pure modules.
- **Over 300 lines**: `search.ts` (315, committed in 5.1.a) and `browse.module.css` (403). Split into
  `search.ts` + `search-sql.ts`, and `browse.module.css` + `card.module.css` + `facets.module.css`.
- **Raw `rgb()`** for the sheet backdrop (token lint failed). Now `var(--color-scrim)`.
- **Cards**: `object-fit` sat on `ResponsiveImage`'s wrapper, so the image could crop; and a `<div>` was inside a
  `<span>`. Now the image is contained on a mat.
- **Duplicate ids/landmarks** from rendering the facet panel twice (sheet + column). Now `idPrefix`.
- `id.json` gained `listing.showResults.one`, but Indonesian has no "one" plural, so `lexicon.test.ts` failed.
  Removed.
