## How the batch insert is done

`payload.db.beginTransaction()` gives the adapter's transaction id; each survivor is inserted with
`payload.create({ collection: 'events', data, overrideAccess: true, req: { transactionID } })` and
the transaction commits — one transaction per batch. When the adapter returns `null` (no
transaction support) it inserts row by row and still counts `insert` drops on failure. There is no
migration and no generated-file change on this branch (payload-types.ts untouched), so nothing to
regenerate; `check:generated` is clean.
