## The route: why the folder is `item/[idSlug]`, and why the public path is unchanged

The public address stays **`/product/{publicId}-{slug}`** (Indonesian `/id/produk/{publicId}-{slug}`), as
EXPERIENCE-GALLERY.md §2 and the route table (`packages/config/src/sites/table.ts`, `item: 'product'` / `'produk'`)
say. What changed is only the **app folder behind it**. The proxy never serves a public path directly: it runs
`parsePublicPath()` and rewrites the request to the surface's internal route, `SURFACE_ROUTES.item.internal =
'item/[idSlug]'` (`packages/config/src/sites/routes/surfaces.ts`), i.e. `app/(gallery)/gallery/[locale]/item/…`.
The worker put the page at `…/[locale]/product/[id]`, a folder the proxy never rewrites to, so every item address
would have answered 404 on every host (the same class of defect `b3e31fd` fixed for the shop's browse and
collection). The page now lives at `app/(gallery)/gallery/[locale]/item/[idSlug]/page.tsx`, and
`routes-exist.test.ts` drops `item` from `NOT_BUILT_YET` (the test asserts the folder exists once a surface is
built). `href('item', …)` still writes `/product/1706-bali`; nothing public moved.

## Review findings and fixes

Fixed in `4c85c4b` unless noted.

1. **Unreachable page** — the route folder above. Also: an old site's slug spelling (`oldItemLink()` passes it
   through with characters no slug has) made the worker's `[a-z0-9-]*` parser return 404; the page now reads any
   slug and answers **308** to the canonical address.
2. **Sold showed an Ask button** ("Ask for another example"). The ticket says sold → no Ask button. Sold now
   shows the *Sold* badge only. (EXPERIENCE-GALLERY §5's table lists "Ask for another example" as a sold
   lead — see Found.)
3. **Tile source not from the C9 key builder.** The worker restated the key shapes because `@engine/media` was
   not a dependency of the web app. `@engine/web` now depends on `@engine/media` (`workspace:*`), and
   `server/gallery/item/images.ts` builds the URLs with `iiifInfoUrl()` and `derivativeKey()` from
   `@engine/media/contract` (the builders `packages/media/src/tiles` keys its output with).
4. **Wrong derivative fallback.** It was always `…/2400.webp`, which does not exist for a source narrower than
   2,400 px (`derivativeWidthsFor()` renders the source's own width as the top). It is now the source width when
   ≤ 2,400, else the 2,400 rung — never past the public cap.
5. **Image order and lead image.** The view model claimed `orderImages('work', …)` order but did not apply it,
   and the page led with `images[0]` even if that was a mockup. Now `orderImages` + `primaryImageIndex` (first
   photographed recto) from the C9 contract; a synthetic image carries `SYNTHETIC_LABEL` and is labelled with
   `image.synthetic.*`.
6. **Media projection.** Relationship sub-fields were in `select`; the media doc is now projected explicitly with
   `populate: { media: ITEM_MEDIA_POPULATE }` (no `master`, no uploader). The db test proves url, alt and role
   arrive.
7. **Cached `null` forever.** An unknown id had no tag to expire, so a work published after someone hit its
   address would 404 until the default profile expired. A `null` now lives `cacheLife('minutes')`.
8. **Record said codes, not words** (`copperplate-engraving`, `map`, `cartographer`), and the worker duplicated
   ~20 labels the app lexicon already has. The record now uses `record.*`, `objectType.*`, `colouring.*`,
   `maker.role.*`, `maker.certainty.*`, `label.stockNumber`; the technique vocabulary (19 codes) gets
   `technique.*` keys in **en and id**.
9. **The whole lexicon shipped to the browser.** `ZoomLazy` (a client component) called `itemText()`. The words
   are now said on the server and passed as props. `ZoomShell`'s labels (zoom in/out, reset, full screen) were
   English defaults on the Indonesian page; they are now from the lexicon.
10. **Double zoom on the keyboard.** OpenSeadragon already answers `+`/`=`, `−`, `0` and the arrows on its own
    canvas and cancels them; the worker's extra listener zoomed again on the bubbled event. It now adds only the
    keypad `+`/`−` and skips cancelled events. The viewport no longer adds a second tab stop.
    `prefers-reduced-motion` cuts the zoom animation (§6).
11. **CSS used `font-size: var(--text-*)`**, but the text tokens are `font` shorthands (`400 size/line family`),
    so the declarations were invalid and the H1 rendered unstyled; and `--leading-tight`, `--weight-semibold` do
    not exist. Now `font: var(--text-*)`.
12. **Lexicon churn.** The worker re-sorted unrelated keys in both files; the files are now main's plus additions
    only. Unused keys (`item.askSold`, `item.versatile`, `item.viewerClose`, …) are gone.
13. **Dependencies.** The lockfile conflict with main was resolved by taking main's lock and re-running
    `pnpm install`. The deprecated `@types/openseadragon` stub was dropped (openseadragon 6.1.1 ships its own
    types). The lock diff against main is exactly `openseadragon@6.1.1` and the `@engine/media` workspace link.
14. **db test**: its 10 s hook timeout failed on this machine (now 180 s, like the catalogue's). It never set an
    `askingPrice`, so "carries no askingPrice" proved little; it now seeds `askingPrice: 18000` and an acquisition
    cost of 7777 and asserts the JSON carries neither figure, nor `physical`, `cataloguing` or `master`.
15. `4c6ba14`: the page image is the largest public derivative once the pipeline made it; the media record's own
    `url` is Payload's file route, which `collections/media/access` serves to owner and editors only.
16. `aa6310b`, found by opening the page: it sat in the shell's prose column, so at 1280 px the record wrapped
    every few letters; it now takes the browse page's full-bleed measure. And when OpenSeadragon cannot open an
    image it printed its own English "Unable to open [object Object]: …" over the viewer; that text is hidden and

## Found

- **EXPERIENCE-GALLERY.md §5** lists "Ask for another example" among a sold work's leads; ticket 5.2b says sold
  shows no Ask button. The ticket was followed. If the owner wants that lead, 5.3 can add it through the WhatsApp
  builder as a prefilled "another example" message.
- **The 9.3 SEO library** (`server/seo/metadata.ts`) prefixes `/id` to one path for both languages, so a page
  whose segment is translated (`/product` · `/produk`, `/browse` · `/jelajah`) gets wrong `hreflang` alternates —
  and a caller that passes `href(…, 'id')` gets `/id/id/…`. The item page calls the library and then sets
  `alternates` and `og:url` from `href()` per locale. The browse page passes `browseHref(…, locale)` and looks
  affected for Indonesian.
- **Public images**: every media `url` is Payload's staff-only file route (`collections/media/access`,
  `registries/storage.ts`), and the derivative pipeline (15.1) has not run, so an anonymous visitor's browser gets
  403 for the item's image — and for the home's and browse's cards, which use the same `url`.
