## What was built

Ported the design team's shared primitives into `engine/apps/web/src/shared/ui/<Component>/` with
`index.ts`, a CSS Module, and one barrel re-export. Components: Button, TextLink, Input, Select,
Checkbox, Textarea, Card, Badge, Eyebrow, Hairline, Header, Footer, FormMessage, Dialog, Toast,
Skeleton.

- CSS Modules read only semantic tokens (`--color-*`, `--space-*`, `--text-*`, etc.); no raw hex,
  `rgb()`, `hsl()` or `font-family` outside token files.
- Server components by default; `'use client'` only on Dialog, Toast and Header.
- Every interactive element has `min-height: 44px` and a visible `:focus-visible` ring using
  `--color-focus`.
- Button: `primary | secondary | quiet` × `default | small`, renders `<a>` when `href` is given,
  supports `loading`.
- TextLink: plain `<a>` (Next.js public pages render per-request, so the project bans `next/link`;
  prefetch is therefore not implemented because the link is never prefetched).
- Form fields: label, hint and error slots wired through `id`/`aria-describedby`, `aria-invalid`
  on error.
- Header: sticky 80 px shell with logo, nav and actions slots and a mobile drawer with
  `aria-expanded` and `aria-controls`.
- Dialog: native `<dialog>` with `showModal`, focus returns to opener on close, Esc closes.
- Toast: fixed `role="status"` live region.
