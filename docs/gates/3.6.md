# Gate 3.6 — the admin as owner, editor and store, in a browser

**Check 3.6.d** and the admin parts of phase 3's **Done when**, driven by Playwright at 1280 px on a production
build (`next build`, then `next start` with `NODE_ENV=production`, `LOCAL_PRODUCTION_BUILD=1`), both hostnames on
one port (4194), the admin on `shop.localhost` only. Ticket `3.6qa`, 2026-10-05, branch `w/3.6qa`.

The GLM worker's 3.6 record is `docs/reports/workers/3.6.md` (unit and db tests for 3.6.a–c, no browser). This
page adds the browser evidence.

## How to re-run

```bash
pnpm worktree:env 3 <id> && pnpm db:fresh          # your own database and port
pnpm build
node tests/e2e/admin/local.mjs start               # the production build on .env.local's PORT (leave running)
pnpm exec playwright test -c tests/e2e/admin       # fixtures are made by the spec itself (fixtures.ts)
```

`tests/e2e/admin/` has its own config: the root `playwright.config.ts` defines projects per test folder and none
covers `tests/e2e/admin`, so `pnpm exec playwright test tests/e2e/admin` finds no tests. The root config is not
this ticket's to change — see **For the orchestrator**. The spec writes its screenshots and `drive.json` (every
count, message and timing it read) to `docs/gates/3.6/`.

**Data:** the shop's mock set (3.7.c files: 120 stores, 80 products, 7,227 stock rows, `WELCOME10`) loaded through
the 3.7.a importer (`runImportPath`, see D8 and D9 for why not through its CLI), plus `fixtures.ts`: an owner, an
editor and two `store` users on two stores (`AMD-001` id 49, `AMD-002` id 50), five orders (49: paid, processing,
delivered; 50: paid, pending payment), three leads (two new), two draft antiques, a condition grade and a maker.

## Fixes made here (owned paths)

- **F1** `engine/packages/cms/src/admin/widgets/dashboard.jsx` — the widgets took their language from the
  `locale` prop, which Payload fills with the *content* locale (an object), so the Indonesian admin got English
  panels; they read `req.i18n.language` now. The owner-only "New leads" panel rendered "New leads: 0" to editors and
  store staff while two leads were new — it renders nothing for them. db test extended (language, null panel).
  Commit `b3961e1`.
- **F2** `engine/packages/cms/src/admin/groups.ts` — the Shop group's Indonesian label was "Toko", which is also
  the Stores collection's Indonesian name, shown in the group beside it ("Toko dan stok" → "Toko"). Now "Toko
  daring". Commit `e490ef5`.
